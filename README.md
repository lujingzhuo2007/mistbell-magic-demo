# 雾钟镇：最后的守夜人

一个无需安装依赖、可直接打开的单页 3D 魔法世界游戏。直接用浏览器打开 `index.html` 即可。

## 启程

- 首次进入会播放可跳过的序章，并在新建档案前展示「游戏指南」。
- 新巫师可以选择姓名、形象、**魔杖材质**和**出身**：
  - 橡木：生命更高、略减伤，起始掌握「护盾术」。
  - 紫杉：法术伤害更高，起始掌握「星火咒」。
  - 柳木：魔力更高，起始掌握「回春咒」。
  - 平民出身：金币较少，平民 NPC 更友善。
  - 贵族出身：金币与声望更高，部分巫师 NPC 会保持距离。
- 启程页的「旧日档案」可以查看当前档案和之前封存的旅人；读取旧档前会自动封存当前进度。
- 游戏会自动保存到当前浏览器。

## 成长与声望

- 击败敌人、完成委托、发现线索会获得经验；升级提高生命与魔力上限。
- 声望来自委托、精英战和终章；影响部分 NPC 的态度。
- 金币用于星尘商店、旅店和补给。
- 生命归零会被送回镇中心并损失部分金币。

## 主线

1. 序章之后先向马琳、艾德蒙·鸦影和守夜人打听钟声、黑塔与昨夜的影子。
2. 集齐三条线索后进入禁秘森林，击败四角的四名精英：
   - 西：暗影编织者·莫甘娜
   - 南：腐沼巫师·格罗姆
   - 东：骨语者·维克斯
   - 北：镜影巫师·塞拉菲娜
3. 四人全部倒下后，黑塔之门在石阵以南开启；林地守望者会让你从三件传说物品中选择一件。
4. 进入黑塔挑战凯勒·斯威尼。战斗分为暗影、灵魂、绝望三个阶段。
5. 四名精英倒下后，镇务委托板会开放五条预备支线：未寄出的信、月光草的约定、三个名字、失踪的商队、凤凰余烬。完成支线能提高生命/魔力/减伤/攻击，并削弱凯勒的生命与灵魂护盾。
6. 终极战中的凯勒拥有约 980 点生命、三段形态、灵魂护盾、残影召唤、暗影裂隙和 155 秒后的狂暴；不完成支线也能挑战，但会非常困难。
7. 结局分为「永夜钟声」与「钟声重鸣」。后者需要在鸦影古堡解锁隐藏技能「灵魂安息」。

## 路线指引

- 画面左上会显示当前主线的下一站、提示和距离。
- 场景中有金色地面箭头、引路光点和目标光柱；小地图会画出目标方向与金色标记。
- 目标在其他建筑或地图时，指引会先带你到正确的门、出口或黑塔之门，切换地图后自动续到下一站。
- 按 `R` 或点击路线面板可以隐藏 / 恢复指引；偏好会保存在当前浏览器。

## 城镇与设施

- **星尘商店**：奥利凡·星尘出售初级/强效治疗药剂、魔力药剂、旅人干粮、学徒长袍、专注指环、守夜人护符、魔力增幅护符、暗影抗性斗篷、凤凰羽毛魔杖核心，以及温室种子和肥料。
- **镇务委托板**：赫敏娜·铁笔负责登记日常、紧急与高危委托。
- **鸦影古堡**：艾德蒙·鸦影管理古籍与魔法学习。
- **星月喷泉**：白天恢复 10 点体力，夜晚恢复 25 点体力。
- **渡鸦旅店**：马琳经营，5 金币休息到清晨；一楼 4 张床、二楼 2 张床。二楼露台可进入真实雾钟镇夜景俯瞰，而不是静态插图。
- **守夜人密室**：第一代守夜人的石像回声。
- **草药温室**：萝丝玛丽管理。星尘商店出售月光草、银叶薄荷、星露花种子和草药肥料；中央通道两侧有四块种植床，可播种、浇水、施肥，成熟后收获。植物会随游戏时间生长，睡觉或研读也会推进生长。
- **禁秘森林**：四名精英各守一角；森林深处的黑塔是终章入口。夜晚有概率出现极光，绿色与紫色的光带会越过树梢，出现时间不定。

## 操作

- Windows：点击 3D 画面锁定鼠标后移动鼠标环视，`Esc` 释放。Mac：不需要锁定鼠标，使用三指拖动（或在画面内按住拖动）环视。
- `W A S D` 移动，`Shift` 奔跑。
- `空格` 跳跃，按住 `Ctrl` 蹲下。
- `E` 互动 / 进出门 / 上二楼。
- `F` 战斗中施法，`H` 使用治疗药剂。
- `M` 地图，`T` 昼夜，`V` 第一 / 第三人称，`R` 更换表情（展示 5 秒），`G` 路线指引。
- `H` 使用最佳治疗用品，`J` 使用魔力药剂；两者共用 9 秒冷却。
- 右下角 `♪` 开关背景音乐；旅人档案里可以调音量。配乐由浏览器实时生成，无外部音频文件。
- 靠近 NPC 按 `E` 后可以输入文字交谈，`Enter` 发送。

## 运行文件

- `index.html`：3D 游戏本体。
- `assets/raven-castle.glb`：Blender 场景。
- `assets/raven-castle-data.js`：`file://` 直接打开时的模型回退。
- `vendor/three-gltf.min.js`：Three.js + GLTFLoader。
- `README.md`、`LICENSE`：说明与许可。
