# 雾钟镇：魔法世界

一个无需安装依赖的单页 2D 魔法世界游戏。打开 `index.html` 即可游玩，使用 WASD 移动、靠近地点后按 E 互动。

## 玩家档案

主菜单中的「设置姓名与巫师形象」可自定义旅人姓名和巫师 emoji。档案、地图进度与角色数据保存在当前浏览器的本地存储中；不同访客的浏览器数据彼此独立。

## 发布到 GitHub Pages

仓库包含 Pages 自动发布工作流。将项目推送到 GitHub 仓库的 `main` 分支后，在仓库 Settings → Pages 中将发布来源设为 GitHub Actions。工作流完成后，仓库会显示可分享的游戏网址。

本项目不依赖外部库、图片或服务器。
